Movie Industry Performance Analysis

Project Overview

This project focuses on analyzing movie industry performance using Microsoft Excel. The dataset was cleaned, transformed, and analyzed to identify trends in IMDb ratings, global box office collections, voting patterns, genre performance, and country-wise movie distribution.

---

Tools & Features Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Dashboard Design
- Data Cleaning
- IF Statements
- Profit Calculation
- Profit Percentage Analysis
- Conditional Formatting
- Data Filtering & Sorting

---

Data Cleaning Process

The raw movie dataset was cleaned and prepared by:

- Removing duplicates
- Handling missing values
- Formatting inconsistent data
- Creating calculated columns
- Organizing data for dashboard visualization

---

Calculations Performed

Profit Calculation

Profit was calculated using:

= Gross Revenue - Budget

Profit Percentage

Profit percentage was calculated using:

= (Profit / Budget) * 100

IF Statement Usage

IF statements were used for:

- Profit/Loss identification
- Rating categorization
- Performance analysis
